## רינדור מחדש
1. פונטים Rubik + Assistant + Noto Color Emoji ב-~/.fonts, `fc-cache -f`.
2. תיקיית עבודה W: `scripts/` (כל מה שב-source/scripts), `shots/` (כל מה שב-source/shots), `vo/`, ו-`3d/` עם `npm install three@0.169.0` ו-`3d/fonts/Rubik-900.ttf`.
3. שרת מקומי: `cd W && python3 -m http.server 8765 --bind 127.0.0.1` (מודולים לא עובדים מ-file://).
4. `MAX_TEMPO=1.04 VOICE_ID=TX3LPaxmHKxFdv7VOQHJ RENDER=renderfull3d.js python3 vo/build_vo.py W s4` (סרטון אחד לכל תהליך; בתוכנית החינמית של ElevenLabs שלוש קריאות במקביל מחזירות 429). עם קול עברי אחרי שדרוג ElevenLabs: `VOICE_ID=PBHwEnXdzx0yfhIO2UCH` (Dorian).
5. הקריינות: `vo/lines.json`. הסצנות: `scripts/stages3d.js`, הדמויות והאביזרים: `scripts/lib3d.js`, הזמנים: `spec_sN.js`.
6. צילום המסך של שיעור 0.1 בטלפון (`shots/l01q.png`) נוצר עם `scripts/capture_app.js` מהאפליקציה עצמה.
