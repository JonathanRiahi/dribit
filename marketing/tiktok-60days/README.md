# דריבית: "60 הימים של נועם" (טיקטוק, 28.8 שניות)

קובץ: dribit_60days.mp4 (1080x1920, 30fps, קריינות ElevenLabs Liam, eleven_v3 עברית, מוזיקה מסונתזת בלי זכויות).

סיפור: יום 1 אחרי השחרור, יש 60 יום → יום 14 הפיקדון נפתח (למטרות המותרות) → כולם יודעים מה לעשות עם הכסף שלו → נועם עוצר ולומד בדריבית (מסכים אמיתיים משיעור 2.3) → יום 60 המענק נכנס, ויש תוכנית (קרן חירום / חיסכון / ליהנות) → נכנסים ל-dribit.app ומתחילים.

כיתוב מוצע: "60 הימים אחרי השחרור קובעים מה יקרה לכסף שלך. מה אתם הייתם עושים ביום ה-14? 👇 #חיילים #שחרור #פיקדון #כסף"
