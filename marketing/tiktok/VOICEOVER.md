# דיבוב לשלושת סרטוני הטיקטוק (2026-10-26)

הסרטונים המוכנים (בלי קול): dribit_tiktok_t1..t3.mp4 בתיקייה הזו, וגם בענף `claude/project-thread-ozcy7y` של JonathanRiahi/dribit תחת marketing/tiktok/ (כולל source/: engine2.html, spec_t1..t3.js, צילומי המסך).

איך מרנדרים מחדש עם קול: מעתיקים את marketing/tiktok/source + marketing/reels/source/scripts (renderfull.js, events.js, music.py, encode.sh) לתיקיית עבודה, מתקינים Rubik + Assistant מ-Google Fonts, מייצרים את הקול דרך ElevenLabs API (מודל eleven_v3 או eleven_multilingual_v2, קול עברי צעיר מה-Voice Library), מודדים את אורך כל משפט, מותחים `dur` של הסצנה המתאימה ב-spec כך שהמשפט נכנס, מרנדרים, ומערבבים: קול ב-0 dB, מוזיקה מונמכת ~10 dB מתחת לקול (sidechain או volume=0.3). היעד נשאר 15 שניות; אם הקול ארוך, מקצרים את סצנת ה-end ל-2.8 ומעלים מהירות קריאה (speed 1.1).

ElevenLabs: `POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}` עם header `xi-api-key: $ELEVENLABS_API_KEY`, body `{"text": ..., "model_id": "eleven_multilingual_v2"}`; רשימת קולות: `GET /v1/voices` (לסנן labels.language=he או לחפש קול שמסומן Hebrew). לכתוב מספרים במילים.
